## 🔄 **数据流架构详解**

### **1. 用户请求流程：**

```
用户操作 (前端)
    ↓
API路由 (app/api/)
    ↓
业务逻辑 (lib/)
    ↓
数据库适配器 (lib/database/)
    ↓
具体数据库 (腾讯云/Supabase)
    ↓
返回数据 (JSON)
    ↓
前端更新 (React状态)
```

### **2. 数据库选择逻辑：**

```typescript
// 在 app/page.tsx 中
const { isChina } = useGeo()  // 获取用户IP位置

// 创建数据库适配器
const dbAdapter = user.type === "authenticated" && user.id
  ? createDatabaseAdapter(isChina, user.id)  // 根据IP选择数据库
  : null

// 使用适配器
const favorites = await dbAdapter?.getFavorites()
```

### **3. 适配器工厂模式：**

```typescript
// lib/database/adapter.ts
export function createDatabaseAdapter(isChina: boolean, userId: string) {
  if (isChina) {
    console.log('🇨🇳 [DB] 使用腾讯云数据库')
    return new CloudBaseAdapter(userId)  // 腾讯云实现
  } else {
    console.log('🌍 [DB] 使用Supabase数据库')
    return new SupabaseAdapter(userId)   // Supabase实现
  }
}
```

export async function GET(req: NextRequest) {
  // 1. 验证JWT Token
  const token = req.headers.get('authorization')?.replace('Bearer ', '')
  
  // 2. 解析用户信息
  const user = await verifyToken(token)
  
  // 3. 创建数据库适配器
  const dbAdapter = createDatabaseAdapter(user.isChina, user.id)
  
  // 4. 执行业务逻辑
  const data = await dbAdapter.getFavorites()
  
  // 5. 返回数据
  return NextResponse.json(data)
}

### **腾讯云实现：**

```typescript
// lib/database/cloudbase-adapter.ts
export class CloudBaseAdapter implements IDatabaseAdapter {
  private userId: string
  
  constructor(userId: string) {
    this.userId = userId
  }
  
  async getFavorites(): Promise<string[]> {
    const res = await wechatDB.collection('web_favorites')
      .where({ user_id: this.userId })
      .get()
    
    return res.data.map((fav: any) => fav.site_id)
  }
  
  async addFavorite(siteId: string): Promise<boolean> {
    try {
      await wechatDB.collection('web_favorites').add({
        user_id: this.userId,
        site_id: siteId,
        created_at: new Date()
      })
      return true
    } catch (error) {
      console.error('腾讯云添加收藏失败:', error)
      return false
    }
  }
}
```

### **Supabase实现：**

```typescript
// lib/database/supabase-adapter.ts
export class SupabaseAdapter implements IDatabaseAdapter {
  private userId: string
  
  constructor(userId: string) {
    this.userId = userId
  }
  
  async getFavorites(): Promise<string[]> {
    const { data, error } = await supabase
      .from('web_favorites')
      .select('site_id')
      .eq('user_id', this.userId)
    
    if (error) {
      console.error('Supabase获取收藏失败:', error)
      return []
    }
    
    return data.map(fav => fav.site_id)
  }
  
  async addFavorite(siteId: string): Promise<boolean> {
    const { error } = await supabase
      .from('web_favorites')
      .insert({
        user_id: this.userId,
        site_id: siteId,
        created_at: new Date().toISOString()
      })
    
    if (error) {
      console.error('Supabase添加收藏失败:', error)
      return false
    }
    
    return true
  }
}
```

## 🌍 **IP检测和路由架构**

### **IP检测流程：**

```
用户访问网站
    ↓
前端调用IP检测API
    ↓
获取用户IP地址
    ↓
调用地理位置API
    ↓
判断是否为中国IP
    ↓
设置 isChina 状态
    ↓
影响UI显示和数据库选择
```

### **IP检测实现：**

```typescript
// contexts/geo-context.tsx
export function GeoProvider({ children }: { children: React.ReactNode }) {
  const [isChina, setIsChina] = useState(false)
  const [loading, setLoading] = useState(true)
  
  useEffect(() => {
    async function detectLocation() {
      try {
        // 调用IP检测API
        const response = await fetch('/api/geo/detect')
        const data = await response.json()
        
        setIsChina(data.isChina)
      } catch (error) {
        console.error('IP检测失败:', error)
        setIsChina(false)  // 默认海外
      } finally {
        setLoading(false)
      }
    }
    
    detectLocation()
  }, [])
  
  return (
    <GeoContext.Provider value={{ isChina, loading }}>
      {children}
    </GeoContext.Provider>
  )
}
```

// 在API路由中
export async function POST(req: NextRequest) {
  try {
    // 1. 参数验证
    const data = await req.json()
    if (!data.userId) {
      return NextResponse.json(
        { error: '用户ID不能为空' },
        { status: 400 }
      )
    }
    
    // 2. 业务逻辑
    const dbAdapter = createDatabaseAdapter(isChina, data.userId)
    const result = await dbAdapter.addFavorite(data.siteId)
    
    if (!result) {
      return NextResponse.json(
        { error: '添加收藏失败' },
        { status: 500 }
      )
    }
    
    // 3. 返回成功
    return NextResponse.json({ success: true })
    
  } catch (error) {
    console.error('API错误:', error)
    return NextResponse.json(
      { error: '服务器内部错误' },
      { status: 500 }
    )
  }
}
```

// JWT Token验证
export async function verifyToken(token: string) {
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET!)
    return decoded
  } catch (error) {
    throw new Error('Token验证失败')
  }
}

// 请求频率限制
const rateLimit = new Map()

export function checkRateLimit(ip: string) {
  const now = Date.now()
  const windowMs = 15 * 60 * 1000 // 15分钟
  const maxRequests = 100
  
  if (!rateLimit.has(ip)) {
    rateLimit.set(ip, { count: 1, resetTime: now + windowMs })
    return true
  }
  
  const limit = rateLimit.get(ip)
  if (now > limit.resetTime) {
    limit.count = 1
    limit.resetTime = now + windowMs
    return true
  }
  
  if (limit.count >= maxRequests) {
    return false
  }
  
  limit.count++
  return true
}
```

## 🎯 **总结：后端如何支撑前端**

### **核心支撑逻辑：**

```
1. 数据支撑
   前端需要数据 → 数据库适配器 → 具体数据库 → 返回数据

2. 功能支撑
   前端用户操作 → API路由 → 业务逻辑 → 数据库操作 → 返回结果

3. 状态支撑
   前端状态变化 → Context更新 → API调用 → 数据库更新 → 状态同步

4. 性能支撑
   前端快速响应 → 缓存策略 → 数据库优化 → CDN加速 → 用户体验

5. 安全支撑
   前端安全操作 → Token验证 → 权限控制 → 数据加密 → 安全保护
```

### **关键设计模式：**

- **适配器模式：** 统一数据库操作接口
- **工厂模式：** 根据条件创建不同实现
- **中间件模式：** 处理认证、验证、错误处理
- **策略模式：** 根据IP选择不同策略
- **观察者模式：** 状态变化通知
