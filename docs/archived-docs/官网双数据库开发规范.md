## 💾 数据备份与年度报告需求

### 需求说明

**Jeff原话：**
> "官网和小程序数据库是独立的，但后期如果需要年度报告，还需要把这两套数据库拷贝出来到公司的U盘备份"

### 需求解读

```
定期（如年底）需要：
  1. 从腾讯云导出数据
     - sitehub_* 表（小程序数据）
     - web_* 表（官网国内用户）
  
  2. 从Supabase导出数据
     - sitehub_* 表（小程序海外用户）
     - web_* 表（官网海外用户）
  
  3. 合并统计
     - 总用户数
     - 总收入
     - 按平台分析
     - 按地区分析
  
  4. 保存到U盘
     - JSON格式（原始数据）
     - CSV格式（Excel可打开）
     - PDF格式（年度报告）
```

### 实现方案对比

#### 方案A：手动导出（简单，当前推荐）

**步骤：**
1. 登录腾讯云控制台 → 导出数据 → 下载JSON
2. 登录Supabase控制台 → 导出数据 → 下载CSV
3. 手动合并数据（用Excel或Python脚本）
4. 保存到U盘

**优点：**
- ✅ 不需要写代码
- ✅ 灵活可控
- ✅ 适合低频操作（一年一次）

**缺点：**
- ❌ 手动操作，需要技术人员
- ❌ 可能出错

**适用场景：** 年度报告（低频需求）

---

#### 方案B：自动化导出（复杂，后期可做）

**步骤：**
1. 创建管理后台 → 数据导出页面
2. 实现导出API → 自动连接两个数据库
3. 一键导出 → 自动合并 → 生成报表
4. 下载到本地 → 保存U盘

**优点：**
- ✅ 自动化，减少人工
- ✅ 不易出错
- ✅ 可以定时自动备份

**缺点：**
- ❌ 需要开发时间（4-5小时）
- ❌ 增加代码复杂度

**适用场景：** 频繁备份（每月/每周）

### 2. 数据库适配器（核心）

#### 统一接口设计

**文件：** `lib/database/adapter.ts`

```typescript
import { db as wechatDB } from './cloudbase-client'
import { createClient } from '@/lib/supabase/client'

const supabase = createClient()

/**
 * 数据库操作适配器
 * 根据用户地区自动选择腾讯云或Supabase
 */
export class DatabaseAdapter {
  private isChina: boolean
  private userId: string

  constructor(isChina: boolean, userId: string) {
    this.isChina = isChina
    this.userId = userId
  }

  // ==========================================
  // 收藏功能
  // ==========================================

  /**
   * 获取收藏列表
   */
  async getFavorites(): Promise<string[]> {
    try {
      if (this.isChina) {
        // 腾讯云
        const res = await wechatDB.collection('web_favorites')
          .where({ user_id: this.userId })
          .get()
        
        console.log('✅ [DB-腾讯云] 获取收藏:', res.data.length)
        return res.data.map((f: any) => f.site_id)
      } else {
        // Supabase
        const { data, error } = await supabase
          .from('web_favorites')
          .select('site_id')
          .eq('user_id', this.userId)
        
        if (error) throw error
        
        console.log('✅ [DB-Supabase] 获取收藏:', data?.length || 0)
        return data?.map(f => f.site_id) || []
      }
    } catch (error) {
      console.error('❌ [DB] 获取收藏失败:', error)
      return []
    }
  }

  /**
   * 添加收藏
   */
  async addFavorite(siteId: string): Promise<boolean> {
    try {
      if (this.isChina) {
        // 腾讯云
        await wechatDB.collection('web_favorites').add({
          user_id: this.userId,
          site_id: siteId,
          created_at: new Date()
        })
        
        console.log('✅ [DB-腾讯云] 添加收藏成功')
      } else {
        // Supabase
        const { error } = await supabase
          .from('web_favorites')
          .insert({
            user_id: this.userId,
            site_id: siteId
          })
        
        if (error) throw error
        
        console.log('✅ [DB-Supabase] 添加收藏成功')
      }
      
      return true
    } catch (error) {
      console.error('❌ [DB] 添加收藏失败:', error)
      return false
    }
  }

  /**
   * 删除收藏
   */
  async removeFavorite(siteId: string): Promise<boolean> {
    try {
      if (this.isChina) {
        // 腾讯云
        await wechatDB.collection('web_favorites')
          .where({
            user_id: this.userId,
            site_id: siteId
          })
          .remove()
        
        console.log('✅ [DB-腾讯云] 删除收藏成功')
      } else {
        // Supabase
        const { error } = await supabase
          .from('web_favorites')
          .delete()
          .eq('user_id', this.userId)
          .eq('site_id', siteId)
        
        if (error) throw error
        
        console.log('✅ [DB-Supabase] 删除收藏成功')
      }
      
      return true
    } catch (error) {
      console.error('❌ [DB] 删除收藏失败:', error)
      return false
    }
  }

  // ==========================================
  // 自定义网站功能
  // ==========================================

  /**
   * 获取自定义网站列表
   */
  async getCustomSites(): Promise<any[]> {
    try {
      if (this.isChina) {
        // 腾讯云
        const res = await wechatDB.collection('web_custom_sites')
          .where({ user_id: this.userId })
          .get()
        
        return res.data
      } else {
        // Supabase
        const { data, error } = await supabase
          .from('web_custom_sites')
          .select('*')
          .eq('user_id', this.userId)
        
        if (error) throw error
        return data || []
      }
    } catch (error) {
      console.error('❌ [DB] 获取自定义网站失败:', error)
      return []
    }
  }

  /**
   * 添加自定义网站
   */
  async addCustomSite(site: any): Promise<boolean> {
    try {
      if (this.isChina) {
        // 腾讯云
        await wechatDB.collection('web_custom_sites').add({
          user_id: this.userId,
          ...site,
          created_at: new Date()
        })
      } else {
        // Supabase
        const { error } = await supabase
          .from('web_custom_sites')
          .insert({
            user_id: this.userId,
            ...site
          })
        
        if (error) throw error
      }
      
      return true
    } catch (error) {
      console.error('❌ [DB] 添加自定义网站失败:', error)
      return false
    }
  }

  // ==========================================
  // 订阅功能
  // ==========================================

  /**
   * 获取用户订阅状态
   */
  async getSubscription(): Promise<any | null> {
    try {
      if (this.isChina) {
        // 腾讯云
        const res = await wechatDB.collection('web_subscriptions')
          .where({ user_id: this.userId })
          .orderBy('created_at', 'desc')
          .limit(1)
          .get()
        
        return res.data[0] || null
      } else {
        // Supabase
        const { data, error } = await supabase
          .from('web_subscriptions')
          .select('*')
          .eq('user_id', this.userId)
          .order('created_at', { ascending: false })
          .limit(1)
          .single()
        
        if (error && error.code !== 'PGRST116') throw error
        return data
      }
    } catch (error) {
      console.error('❌ [DB] 获取订阅失败:', error)
      return null
    }
  }

  /**
   * 创建或更新订阅
   */
  async upsertSubscription(subscription: any): Promise<boolean> {
    try {
      if (this.isChina) {
        // 腾讯云 - 先查询是否存在
        const existing = await this.getSubscription()
        
        if (existing) {
          // 更新
          await wechatDB.collection('web_subscriptions')
            .doc(existing._id)
            .update({
              ...subscription,
              updated_at: new Date()
            })
        } else {
          // 新建
          await wechatDB.collection('web_subscriptions').add({
            user_id: this.userId,
            ...subscription,
            created_at: new Date()
          })
        }
      } else {
        // Supabase - 使用upsert
        const { error } = await supabase
          .from('web_subscriptions')
          .upsert({
            user_id: this.userId,
            ...subscription
          }, {
            onConflict: 'user_id'
          })
        
        if (error) throw error
      }
      
      return true
    } catch (error) {
      console.error('❌ [DB] 更新订阅失败:', error)
      return false
    }
  }
}

/**
 * 工厂函数：根据地区创建适配器
 */
export function createDatabaseAdapter(isChina: boolean, userId: string) {
  return new DatabaseAdapter(isChina, userId)
}
```

## ✨ 核心原则

### 1. 数据隔离原则

```
国内数据 → 只在腾讯云（web_* 集合）
海外数据 → 只在Supabase（web_* 表）
小程序数据 → 通过 sitehub_* 前缀区分
官网数据 → 通过 web_* 前缀区分
```

### 2. IP决定一切原则

```
用户IP → 决定看到什么
        ↓
      国内IP → 人民币、微信、腾讯云
      海外IP → 美元、Google、Supabase
```

### 3. 复制小程序原则

```
小程序已实现且稳定的逻辑 → 直接复制
不要重新发明轮子
保持两个平台的一致性
```
