# 腾讯云Serverless部署指南

## 🎯 为什么要部署到腾讯云？

### **合规性要求：**
- ✅ 国内用户数据不出境
- ✅ 符合《数据安全法》
- ✅ 符合《个人信息保护法》

### **Vercel的问题：**
- ❌ 服务器在美国
- ❌ 国内用户访问会导致数据出境
- ❌ 即使数据最终存在腾讯云，API调用过程中数据已出境

---

## 📋 腾讯云Serverless部署步骤

### **Step 1: 准备工作**

**需要：**
- 腾讯云账号（已有 ✅）
- 已备案的域名（如：mornhub.help）
- GitHub仓库（mvp_8）

---

### **Step 2: 创建Serverless应用**

#### 2.1 登录腾讯云控制台
```
网址：https://console.cloud.tencent.com/ssr
```

#### 2.2 创建Next.js应用
1. 点击 **"新建应用"**
2. 选择 **"Next.js"** 框架
3. 应用名称：`mvp8-official-website`
4. 地域：**中国大陆**（重要！）

#### 2.3 导入代码
- 选择 **"导入已有项目"**
- 授权GitHub
- 选择仓库：`yan888376/mvp_8`
- 分支：`main`

---

### **Step 3: 配置环境变量**

在Serverless应用配置中添加：

#### 3.1 基础配置
```bash
# 网站URL
NEXT_PUBLIC_SITE_URL=https://mornhub.help

# Supabase（海外用户）
NEXT_PUBLIC_SUPABASE_URL=https://ykirhilnbvsanqyenusf.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=您的密钥
SUPABASE_SERVICE_ROLE_KEY=您的密钥

# 腾讯云（国内用户）
NEXT_PUBLIC_WECHAT_CLOUDBASE_ID=cloudbase-1gnip2iaa08260e5
```

#### 3.2 微信支付配置
```bash
WECHAT_PAY_APP_ID=wx1234567890abcdef
WECHAT_PAY_MCH_ID=1234567890
WECHAT_PAY_SERIAL_NO=证书序列号
WECHAT_PAY_PRIVATE_KEY=私钥内容
WECHAT_PAY_PUBLIC_KEY=公钥内容
WECHAT_PAY_API_V3_KEY=32位密钥
```

#### 3.3 微信登录配置
```bash
WECHAT_APP_ID=wx0987654321fedcba
WECHAT_APP_SECRET=应用密钥
```

#### 3.4 支付宝配置
```bash
NEXT_PUBLIC_ALIPAY_APP_ID=2021005199628151
ALIPAY_PRIVATE_KEY=您的私钥
ALIPAY_PUBLIC_KEY=支付宝公钥
```

#### 3.5 Stripe和PayPal配置
```bash
STRIPE_SECRET_KEY=sk_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_...
PAYPAL_CLIENT_ID=您的ID
PAYPAL_CLIENT_SECRET=您的密钥
PAYPAL_MODE=live
```

---

### **Step 4: 配置自定义域名**

#### 4.1 添加域名
1. 在Serverless应用中
2. 点击 **"域名管理"**
3. 添加自定义域名：`mornhub.help`

#### 4.2 配置DNS解析
在域名管理处（如阿里云）添加CNAME记录：
```
类型：CNAME
主机记录：@
记录值：（腾讯云提供的CNAME地址）
```

#### 4.3 配置SSL证书
- 腾讯云免费SSL证书
- 或上传已有证书

---

### **Step 5: 部署应用**

1. 配置完成后，点击 **"部署"**
2. 等待构建完成（5-10分钟）
3. 访问域名验证

---

### **Step 6: 配置CDN加速（可选）**

#### 6.1 开启CDN
1. 腾讯云CDN控制台
2. 添加加速域名：`mornhub.help`
3. 源站：Serverless应用地址

#### 6.2 缓存配置
- 静态文件：缓存1天
- API路由：不缓存
- 页面：缓存1小时

## 📞 需要帮助？

### **常见问题：**

**Q1: 部署失败怎么办？**
A: 查看构建日志，通常是环境变量配置问题

**Q2: 国内访问还是慢？**
A: 开启CDN加速，配置合适的缓存策略

**Q3: 数据库连接超时？**
A: 检查腾讯云和Supabase的网络配置

**Q4: 需要ICP备案吗？**
A: 是的，域名必须备案才能使用
