# 📚 项目文档目录

本目录包含所有项目相关的文档、测试文件、备份和归档资料。

## 📁 目录结构

```
docs/
├── markdown/           # Markdown 格式的文档
├── testing/            # 测试脚本和工具
├── guides/             # 操作指南
├── build-system/       # 四端构建系统文档
├── backup-old/         # 历史备份文件
└── archived-docs/      # 归档的历史文档
```

## 📖 文档分类说明

### 1. markdown/ - Markdown 文档

- 密码重置相关工具脚本

### 3. guides/ - 操作指南
- Jeff 关键任务操作指南
- 环境变量配置清单
- Vercel 部署脚本

### 4. build-system/ - 构建系统
- **四端应用GitHub Actions自动构建经验总结与完整实施方案.txt** (必读)
- 四端自动构建使用指南.md

### 5. backup-old/ - 历史备份
- 数据库修复脚本

### 6. archived-docs/ - 归档文档
