# 国内用户自定义网站不同步到数据库问题修复

## 📅 日期
2025-11-05

## 🐛 问题描述

### 用户报告
Jeff测试发现：

### 现象
- 国内用户添加自定义网站后
- 刷新页面，自定义网站消失
- 数据库 `web_custom_sites` 集合无任何记录
- 与收藏功能完全相同的问题

## 🔍 根本原因分析

### 问题根源（与收藏功能完全相同）
```
国内用户的认证方式：
用户登录 → JWT Token (localStorage) → 服务端API验证

app/page.tsx 使用的方式：
CloudBase Client SDK → 需要客户端登录凭证 → 报错"credentials not found"
```

### 数据流程对比

**国内用户实际认证：**
```
JWT Token (localStorage) → /api/custom-sites-cn → CloudBase Node SDK (SecretID/SecretKey)
```

**代码使用的方式：**
```
❌ CloudBase Client SDK (需要客户端登录凭证，但不存在)
```

## ✅ 解决方案

### 修复策略
使用与收藏功能完全相同的模式：
1. 创建服务端API（使用CloudBase Node SDK）
2. 修改客户端库（添加地区检测和路由）
3. 修改页面组件（国内用户调用API，海外用户使用adapter）

### 实施步骤

#### 2. 修改客户端库
**文件：** `lib/custom-websites.ts`

```typescript
// 添加地区检测
function getUserRegion(): 'china' | 'overseas' {
  if (typeof window === 'undefined') return 'overseas'
  try {
    const userInfo = localStorage.getItem('user_info')
    if (userInfo) {
      const user = JSON.parse(userInfo)
      return user.region === 'china' ? 'china' : 'overseas'
    }
  } catch (e) {
    console.error('获取用户地区失败:', e)
  }
  return 'overseas'
}

// 修改所有函数添加路由逻辑
export async function getCustomWebsites(userId: string): Promise<CustomWebsite[]> {
  const region = getUserRegion()

  if (region === 'china') {
    // 🇨🇳 国内用户：调用API
    const token = localStorage.getItem('user_token')
    const res = await fetch('/api/custom-sites-cn', {
      method: 'GET',
      headers: { 'Authorization': `Bearer ${token}` }
    })
    const result = await res.json()
    return (result.sites || []).map(site => ({
      id: site._id,
      user_id: site.user_id,
      name: site.name,
      url: site.url,
      icon: site.logo,
      category: site.category || 'custom',
      // ...
    }))
  } else {
    // 🌍 海外用户：使用Supabase
    const { data, error } = await supabase
      .from('custom_websites')
      .select('*')
      .eq('user_id', userId)
    return data || []
  }
}
```
