                    第三部分：正确的问题根源分析方法
================================================================================

【3.1 错误日志的真正含义】

重新审视错误：
```
❌ [DB-腾讯云] 获取收藏失败: credentials not found
```

这个错误来自哪里？
➡️ 搜索代码：`grep -r "DB-腾讯云.*获取收藏失败"`
➡️ 发现：`lib/database/cloudbase-adapter.ts`

关键发现：
**错误来自 CloudBase Adapter，不是来自 lib/favorites.ts！**

【3.2 追踪调用链】

第一步：谁在使用 lib/favorites.ts？
```bash
grep -r "from.*@/lib/favorites" --include="*.tsx" --include="*.ts"
```
结果：**只有 hooks/use-favorites.ts 导入了它**

第二步：谁在使用 use-favorites hook？
```bash
grep -r "useFavorites" --include="*.tsx" --include="*.ts"
```
结果：**空！没有任何组件使用这个hook！**

第三步：谁在实际加载收藏？
```bash
grep -n "dbAdapter.getFavorites" app/page.tsx
```
结果：**app/page.tsx 第394行在调用 dbAdapter.getFavorites()！**

【3.3 问题根源确认】

真正的数据流：
```
用户登录
  ↓
app/page.tsx 调用 dbAdapter.getFavorites()
  ↓
lib/database/adapter.ts 创建 CloudBaseAdapter
  ↓
lib/database/cloudbase-adapter.ts 使用客户端SDK
  ↓
CloudBase 客户端SDK 检查登录凭据
  ↓
❌ 没有凭据！报错 "credentials not found"
```

**根源：**
- 国内邮箱用户通过 JWT token 认证（服务端）
- 但 app/page.tsx 使用 CloudBase客户端SDK（需要客户端登录）
- 这两个是**完全不同的认证系统**！

我修改的 lib/favorites.ts 完全没有被调用！

================================================================================
                    第四部分：最终解决方案
================================================================================

【4.1 解决方案】

核心思路：让国内用户使用服务端API，而不是客户端SDK

修改 app/page.tsx：
1. 导入 lib/favorites.ts 的函数
2. 在 loadFavorites 中判断 isChina
   - 国内用户：调用 getFavorites(userId) API
   - 海外用户：继续使用 dbAdapter.getFavorites()
3. 在 toggleFavorite 中判断 isChina
   - 国内用户：调用 addToFavorites/removeFromFavorites API
   - 海外用户：继续使用 dbAdapter
4. 在其他收藏操作中同样判断 isChina

【4.2 代码修改示例】

修改前（第388-416行）：
```typescript
if (user.type === "authenticated" && user.id && dbAdapter) {
  const favoriteSiteIds = await dbAdapter.getFavorites()
  setFavorites(favoriteSiteIds)
}
```

修改后：
```typescript
if (user.type === "authenticated" && user.id) {
  if (isChina) {
    // 🇨🇳 国内用户：调用服务端API
    const favoritesData = await getFavorites(user.id)
    const favoriteSiteIds = favoritesData.map(f => f.site_id)
    setFavorites(favoriteSiteIds)
  } else if (dbAdapter) {
    // 🌍 海外用户：使用adapter
    const favoriteSiteIds = await dbAdapter.getFavorites()
    setFavorites(favoriteSiteIds)
  }
}
```

✅ 不再报 "credentials not found" 错误
✅ 海外用户不受影响
✅ 构建成功，无新错误
