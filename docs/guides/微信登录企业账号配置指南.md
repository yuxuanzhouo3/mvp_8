# 微信登录企业账号配置完整指南

## 📋 概述

现在你已经有了企业注册的微信开放平台开发者账号，可以完成微信登录的配置了。本项目已经实现了完整的微信登录功能代码，只需要完成配置即可使用。

---

## ✅ 第一步：在微信开放平台创建网站应用

### 1.1 登录微信开放平台

1. 访问：https://open.weixin.qq.com/
2. 使用**企业账号**登录（不是个人账号）
3. 如果还没有完成企业认证，需要先完成认证（通常需要1-3个工作日）

### 1.2 创建网站应用

1. 登录后，点击顶部导航：**管理中心**
2. 左侧菜单选择：**网站应用**
3. 点击右上角：**创建网站应用**

### 1.3 填写应用信息

需要填写以下信息：

| 字段 | 填写内容 | 说明 |
|------|---------|------|
| **应用名称** | MornHub（或你的产品名称） | 显示在微信登录页面的应用名称 |
| **应用简介** | 智能网站导航平台 | 简短描述你的应用功能 |
| **应用官网** | https://mornhub.help | 你的网站域名（必须使用 https） |
| **应用图标** | 上传应用 Logo | 建议 512x512 像素，PNG格式 |
| **授权回调域** | mornhub.help | ⚠️ 重要：只填域名，不要带协议和路径 |

**⚠️ 重要注意事项：**
- 授权回调域只填写：`mornhub.help`（不要写 `https://mornhub.help`）
- 应用官网必须使用 HTTPS
- 审核通过通常需要 1-3 个工作日（企业账号可能更快）

### 1.4 提交审核并等待通过

1. 检查所有信息无误后，点击**提交审核**
2. 等待审核通过（通常 1-3 个工作日）
3. 审核通过后，你会收到微信通知

---

## ⏳ 审核等待期间：可以提前做的准备工作

**是的，必须等审核通过后才能使用微信登录功能**，但在等待期间可以提前完成以下准备工作：

### ✅ 准备工作清单

#### 1. 准备环境变量（可以先配置，等审核通过后补充 AppID 和 Secret）

创建或编辑 `.env.local` 文件，先配置能配置的部分：

```bash
# ============================================
# 网站URL配置（可以先配置）
# ============================================
# 本地开发时使用：
NEXT_PUBLIC_SITE_URL=http://localhost:3000
# 生产环境改为：
# NEXT_PUBLIC_SITE_URL=https://mornhub.help

# ============================================
# JWT密钥配置（可以先配置）
# ============================================
# 用于生成登录Token，请使用强密码（至少32位）
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production

# ============================================
# 微信登录配置（等审核通过后再填写）
# ============================================
WECHAT_APP_ID=等待审核通过后填写
WECHAT_APP_SECRET=等待审核通过后填写

# ============================================
# 腾讯云CloudBase配置（如果还没配置）
# ============================================
NEXT_PUBLIC_WECHAT_CLOUDBASE_ID=cloudbase-xxxxxxxxx
CLOUDBASE_SECRET_ID=your_cloudbase_secret_id
CLOUDBASE_SECRET_KEY=your_cloudbase_secret_key
```

#### 2. 配置腾讯云 CloudBase（如果还没配置）

如果还没有配置腾讯云 CloudBase，现在可以先去配置：

1. **登录腾讯云控制台**
   - 访问：https://console.cloud.tencent.com/tcb
   - 使用企业账号登录

2. **创建云开发环境**
   - 点击"创建环境"
   - 填写环境名称（如：`sitehub-prod`）
   - 选择套餐（按量付费即可）
   - 创建完成后，记录环境ID（格式：`cloudbase-xxxxxxxxx`）

3. **创建数据库集合**
   在云开发控制台 → 数据库 → 创建以下集合：
   - `web_users` - 用户表
   - `web_favorites` - 收藏表
   - `web_custom_sites` - 自定义网站表
   - `web_subscriptions` - 订阅表
   - `web_payment_transactions` - 支付交易表

4. **获取API密钥**
   - 访问：https://console.cloud.tencent.com/cam/capi
   - 点击"新建密钥"（或使用已有密钥）
   - 复制 `SecretId` 和 `SecretKey`
   - ⚠️ 保密这两个值！

#### 3. 检查代码和配置

运行配置检查脚本（等审核通过后填入 AppID 和 Secret 再检查）：

```bash
npm run check:wechat
```

#### 4. 准备生产环境配置

如果使用 Vercel 部署，可以先在 Vercel Dashboard 中配置其他环境变量（除了 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET` 等审核通过后再填）。

### ⚠️ 重要提醒

- **审核通过后必须做的事：**
  1. ✅ 立即获取 AppID 和 AppSecret（AppSecret 只显示一次）
  2. ✅ 将 AppID 和 AppSecret 添加到环境变量
  3. ✅ 确认授权回调域已正确配置
  4. ✅ 重新部署应用（如果修改了环境变量）
  5. ✅ 测试微信登录功能

- **审核状态查看：**
  - 登录微信开放平台：https://open.weixin.qq.com/
  - 进入：管理中心 → 网站应用
  - 查看应用状态，会显示"审核中"、"已通过"或"已拒绝"

## 🔑 第二步：获取应用凭证（审核通过后）

### 2.1 查看应用详情

审核通过后：

1. 进入**管理中心** → **网站应用**
2. 找到你创建的应用，点击应用名称进入详情页
3. 在详情页可以看到：
   - **AppID**（应用ID）
   - **AppSecret**（应用密钥）⚠️ 只显示一次，请立即保存

### 2.2 记录重要信息

将以下信息保存到安全的地方：

```
WECHAT_APP_ID=wx_xxxxxxxxxxxxxxxx          # 从"应用ID"复制
WECHAT_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx  # 从"应用密钥"复制（只显示一次）
```

⚠️ **安全提醒：**
- AppSecret 只显示一次，请立即复制保存
- 不要分享给任何人
- 不要提交到代码仓库

## 🔐 第三步：配置授权回调域

### 3.1 确认回调域配置

1. 在应用详情页，找到**授权回调域**设置
2. 确保已填写：`mornhub.help`
3. 如果有多个域名，可以添加多个：
   - `mornhub.help`（主域名）
   - `site.mornscience.top`（备选域名）

### 3.2 回调域格式要求

✅ **正确格式：**
```
mornhub.help
```

❌ **错误格式：**
```
https://mornhub.help                    # 不要带协议
https://mornhub.help/api/auth/wechat/callback  # 不要带路径
mornhub.help/                          # 不要带斜杠
```

```bash
# ============================================
# 网站URL配置（必须）

# ============================================

# ============================================
# 从腾讯云控制台获取
NEXT_PUBLIC_WECHAT_CLOUDBASE_ID=cloudbase-xxxxxxxxx
CLOUDBASE_SECRET_ID=your_cloudbase_secret_id
CLOUDBASE_SECRET_KEY=your_cloudbase_secret_key
```

### 4.2 获取腾讯云CloudBase配置

如果还没有配置腾讯云CloudBase，需要：

1. **登录腾讯云控制台**

3. **创建数据库集合**
   在云开发控制台 → 数据库 → 创建以下集合：
   - `web_users` - 用户表
   - `web_favorites` - 收藏表
   - `web_custom_sites` - 自定义网站表
   - `web_subscriptions` - 订阅表

4. **获取API密钥**
   - 访问：https://console.cloud.tencent.com/cam/capi
   - 点击"新建密钥"（或使用已有密钥）

   - ⚠️ 保密这两个值！

### 4.3 生产环境配置（Vercel）

如果使用 Vercel 部署：

1. **登录 Vercel Dashboard**
   - 访问：https://vercel.com/dashboard
   - 找到你的项目

2. **配置环境变量**
   - 进入项目 → Settings → Environment Variables
   - 添加以下变量：

| 变量名 | 值 | 是否敏感 |
|--------|-----|---------|
| `WECHAT_APP_ID` | `wx_xxxxxxxxxxxxxxxx` | ✅ 是 |

| `CLOUDBASE_SECRET_KEY` | `你的腾讯云SecretKey` | ✅ 是 |

3. **重新部署**
   - 配置完成后，点击"Redeploy"重新部署
   - 或者推送代码到GitHub触发自动部署

## 🧪 第五步：测试微信登录

### 5.1 本地测试（限制）

⚠️ **重要：** 微信登录**无法在本地 localhost 测试**，因为微信要求回调域名必须是公网可访问的域名。

**解决方案：**
1. **使用内网穿透工具**（如 ngrok）
   ```bash
   # 安装 ngrok
   npm install -g ngrok
   
   # 启动本地服务
   npm run dev
   
   # 在另一个终端启动 ngrok
   ngrok http 3000
   
   # 将 ngrok 提供的域名（如：https://abc123.ngrok.io）配置到微信开放平台
   # 然后使用这个域名访问测试
   ```

2. **直接部署到测试环境**
   - 部署到 Vercel 或腾讯云
   - 使用生产域名 `https://mornhub.help` 测试

### 5.2 生产环境测试步骤

1. **确保所有环境变量已配置**
   - 检查 Vercel 或腾讯云的环境变量是否都已添加

2. **访问网站**
   - 打开：https://mornhub.help
   - 点击右上角"登录"按钮

3. **测试微信登录**
   - 在登录弹窗中，应该能看到绿色的"微信登录"按钮（带"推荐"标签）
   - 点击"微信登录"按钮
   - 应该跳转到微信授权页面（显示二维码）
   - 使用微信扫码授权
   - 授权成功后，应该跳转回网站首页
   - 右上角应该显示你的微信昵称（表示已登录）

4. **验证数据库**
   - 登录腾讯云CloudBase控制台
   - 查看 `web_users` 集合
   - 应该能看到新创建的微信用户记录，包含：
     - `_openid` - 微信OpenID
     - `nickname` - 微信昵称
     - `avatar` - 微信头像
     - `loginType: 'wechat'` - 登录方式标记

## 🚨 常见问题排查

### Q1: 点击"微信登录"后显示"redirect_uri参数错误"

**原因：** 授权回调域未配置或配置错误

**解决方案：**
1. 检查微信开放平台的授权回调域是否填写：`mornhub.help`
2. 确保没有带协议（`https://`）和路径
3. 如果是新配置的，等待几分钟让配置生效

### Q2: 显示"appid参数错误"

**原因：** `WECHAT_APP_ID` 配置错误

**解决方案：**
1. 检查 `.env.local` 或 Vercel 环境变量中的 `WECHAT_APP_ID`
2. 确保值正确（格式：`wx_xxxxxxxxxxxxxxxx`）
3. 如果修改了环境变量，需要重启开发服务器或重新部署

### Q3: 本地测试微信登录无法回调

**原因：** 微信要求回调域名必须是公网可访问的域名

**解决方案：**
- 使用内网穿透工具（如 ngrok）
- 或直接部署到生产环境测试

### Q4: 微信登录后，用户信息没有保存到数据库

**原因：** CloudBase 配置错误或数据库权限问题

**解决方案：**
1. 检查 `NEXT_PUBLIC_WECHAT_CLOUDBASE_ID` 是否正确
2. 检查 `CLOUDBASE_SECRET_ID` 和 `CLOUDBASE_SECRET_KEY` 是否正确
3. 检查数据库集合是否已创建
4. 检查数据库权限设置（需要允许写入）

### Q5: 应用审核被拒绝

**常见原因：**
1. 应用官网无法访问（需要确保网站可以正常访问）
2. 应用简介不符合要求
3. 应用图标不符合要求

**解决方案：**
1. 确保网站可以正常访问（https://mornhub.help）
2. 按照微信要求修改应用信息
3. 重新提交审核
