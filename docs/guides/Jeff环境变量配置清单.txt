任务1: 支付宝支付配置
================================================================================
优先级：⭐⭐⭐ P0（最高优先级，阻塞开发团队）
状态：待开始
所需时间：1-2个工作日
重要性：必须配置才能开发支付API IP路由功能

--------------------------------------------------------------------------------
步骤1: 登录支付宝开放平台
--------------------------------------------------------------------------------
网址：https://open.alipay.com/
账号：使用企业支付宝账号登录

--------------------------------------------------------------------------------
步骤2: 创建网页/移动应用
--------------------------------------------------------------------------------
路径：控制台 → 网页&移动应用 → 创建应用

填写信息：
  应用名称：SiteHub 或 Mornhub
  应用类型：网页应用
  应用网址：https://mornhub.help
  应用简介：智能网站导航平台

--------------------------------------------------------------------------------
步骤3: 生成RSA密钥对
--------------------------------------------------------------------------------
工具：支付宝开放平台提供的密钥生成工具
下载地址：https://opendocs.alipay.com/common/02kipl

操作：
  1. 下载密钥生成工具
  2. 运行工具，选择"RSA2(SHA256)"
  3. 点击"生成密钥"
  4. 保存私钥文件（应用私钥）
  5. 复制公钥，上传到支付宝开放平台

上传公钥：
  路径：应用详情 → 开发设置 → 接口加签方式 → 设置
  上传：应用公钥（从密钥生成工具复制）
  获取：支付宝公钥（支付宝会显示给你）

--------------------------------------------------------------------------------
步骤4: 配置环境变量（关键！）
--------------------------------------------------------------------------------

需要获取的4个值：
┌──────────────────────────────────────────────────────────────────────┐
│ 1. ALIPAY_APP_ID                                                     │
│    位置：应用详情页顶部显示                                           │
│    格式：2021xxxxxxxxxx（纯数字）                                     │
│    示例：2021001165432123                                            │
│                                                                      │
│ 2. ALIPAY_PRIVATE_KEY                                                │
│    位置：密钥生成工具生成的"应用私钥"文件                             │
│    格式：MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC...      │
│    注意：是完整的私钥字符串（很长）                                   │
│                                                                      │
│ 3. ALIPAY_PUBLIC_KEY                                                 │
│    位置：上传公钥后，支付宝会显示"支付宝公钥"                         │
│    格式：MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...             │
│    注意：不是你上传的公钥，是支付宝返回的公钥                         │
│                                                                      │
│ 4. ALIPAY_GATEWAY                                                    │
│    固定值：https://openapi.alipay.com/gateway.do                     │
│    注意：生产环境用这个，测试环境用沙箱地址                           │
└──────────────────────────────────────────────────────────────────────┘

--------------------------------------------------------------------------------
步骤5: 配置到云平台（两个地方都要配置）
--------------------------------------------------------------------------------

配置位置1：Vercel（海外用户 + 国内用户都可用）
  路径：Vercel Dashboard → Settings → Environment Variables
  操作：
    1. 点击 "Add New"
    2. 填写变量名和值
    3. ✅ 勾选 "Sensitive"
    4. ✅ 选择 "Only visible to: Owner"
    5. 点击 "Save"

  需要添加的4个变量：
    Name: ALIPAY_APP_ID
    Value: 2021xxxxxxxxxx

    Name: ALIPAY_PRIVATE_KEY
    Value: MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC...

    Name: ALIPAY_PUBLIC_KEY
    Value: MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...

    Name: ALIPAY_GATEWAY
    Value: https://openapi.alipay.com/gateway.do


配置位置2：腾讯云（国内用户）
  路径：腾讯云控制台 → 云函数 → 环境变量管理
  操作：
    1. 点击 "新增变量"
    2. 填写变量名和值
    3. 点击 "保存"

  需要添加的4个变量：（同上）
    ALIPAY_APP_ID=2021xxxxxxxxxx
    ALIPAY_PRIVATE_KEY=MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQC...
    ALIPAY_PUBLIC_KEY=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...
    ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do

--------------------------------------------------------------------------------
网址：https://console.cloud.tencent.com/tcb

操作：
  1. 点击 "新建环境"
  2. 环境名称：mvp8-web（或自定义）
  3. 计费方式：按量计费（或包年包月）

--------------------------------------------------------------------------------
开通后：
  路径：云开发控制台 → 环境列表 → 查看环境ID

  格式：cloudbase-xxxxxxxxx
  示例：cloudbase-1gnip2iaa08260e5

  保存这个环境ID！

--------------------------------------------------------------------------------
步骤3: 创建5个数据库集合
--------------------------------------------------------------------------------
路径：云开发控制台 → 数据库 → 集合

需要创建的5个集合：
  1. web_users            （用户表）
  2. web_favorites        （收藏表）
  3. web_custom_sites     （自定义网站表）
  4. web_subscriptions    （订阅表）
  5. web_payment_transactions  （支付记录表）

每个集合的操作：
  1. 点击 "新建集合"
  2. 集合名称：填写上面的名称
  3. 点击 "确定"

详细字段说明见：scripts/腾讯云集合创建指南.md

--------------------------------------------------------------------------------
步骤4: 配置权限（重要！）
--------------------------------------------------------------------------------
路径：数据库 → 权限设置

开发阶段（推荐）：
  所有集合：仅创建者可读写

生产阶段：
  需要配置更细致的权限规则

腾讯云：

  Value: cloudbase-xxxxxxxxx

任务5: DNS智能解析配置
================================================================================
优先级：⭐ P2（中优先级）
状态：待开始
所需时间：30分钟
依赖：需要先完成任务6（腾讯云Serverless部署）

--------------------------------------------------------------------------------
主推方案：统一域名 mornhub.help + 智能DNS分流
--------------------------------------------------------------------------------

配置域名：mornhub.help

DNS配置（在域名服务商控制台）：

记录1（海外用户）：
  主机记录：@
  记录类型：CNAME
  线路类型：默认
  记录值：<Vercel地址>.vercel.app
  TTL：600

记录2（国内用户）：
  主机记录：@
  记录类型：CNAME
  线路类型：境内
  记录值：<腾讯云Serverless地址>.ap-guangzhou.app.tcloudbase.com
  TTL：600

--------------------------------------------------------------------------------
备选方案：双域名分别部署
--------------------------------------------------------------------------------

中国用户：
  域名：site.mornscience.top
  指向：腾讯云Serverless

海外用户：
  域名：mornhub.help
  指向：Vercel

验证DNS配置
--------------------------------------------------------------------------------

注意事项和安全提示
================================================================================

1. 环境变量安全：
   ✅ Vercel敏感变量设置为 "Owner可见"
   ✅ 定期轮换密钥（每3个月）
   ✅ 离职员工：立即轮换所有密钥
   ❌ 不要把密钥提交到Git
   ❌ 不要在公开渠道分享密钥

2. 支付宝密钥：
   ⚠️ 私钥只显示一次，立即保存
   ⚠️ 不要混淆"应用公钥"和"支付宝公钥"
   ⚠️ 使用RSA2(SHA256)，不要用RSA

3. 微信密钥：
   ⚠️ WECHAT_APP_SECRET只显示一次，立即保存
   ⚠️ 授权回调域不要带协议和路径
   ⚠️ 微信支付暂不配置（安全原因）

4. 数据库配置：
   ⚠️ 腾讯云集合名称必须以 web_ 开头
   ⚠️ 创建5个集合，不要遗漏
   ⚠️ 权限设置为"仅创建者可读写"

5. DNS配置：
