# 收藏数据快速查看方法

## 🎯 最快的方式（推荐给Jeff）

### 第一步：打开腾讯云控制台

**直达链接：**
https://console.cloud.tencent.com/tcb/db/index?envId=cloudbase-1gnip2iaa08260e5

（如果链接失效，手动访问：控制台 → 云开发 → 选择环境 `cloudbase-1gnip2iaa08260e5` → 数据库）

### 第二步：查看数据表

#### 查看收藏表
1. 点击左侧 **集合管理**
2. 找到并点击 `web_favorites` 集合
3. 就可以看到所有收藏记录了！

#### 查看自定义网站表
1. 点击左侧 **集合管理**
2. 找到并点击 `web_custom_sites` 集合
3. 就可以看到所有自定义网站记录了！

## 📊 如何验证收藏是否成功

### 测试流程：

1. **记录初始数据**
   - 打开 `web_favorites` 集合
   - 记下当前有多少条数据
   - 或者记下最新一条的 `_id`

2. **在官网进行收藏操作**
   - 注册/登录测试账号（比如：test001@example.com）
   - 收藏 3 个网站（比如：ChatGPT, GitHub, Twitter）
   - 退出登录

3. **刷新数据库查看**
   - 回到 CloudBase 控制台
   - 点击刷新按钮 🔄
   - 应该看到新增了 3 条记录
   - 每条记录包含：
     - `user_id`: 用户ID
     - `site_id`: 网站ID（如 "chatgpt"）
     - `created_at`: 创建时间

4. **验证持久化**
   - 重新登录同一账号
   - 检查官网是否显示收藏
   - 同时数据库中的记录应该依然存在（没有被删除）

## 🔍 查找特定用户的收藏

### 方法1：通过邮箱找用户ID

1. 在 `web_users` 集合中搜索邮箱
2. 找到对应的 `_id` 字段（这就是 user_id）
3. 复制这个 ID

### 方法2：在收藏表中筛选

1. 在 `web_favorites` 集合中
2. 点击 **查询** 按钮
3. 添加筛选条件：`user_id` 等于上面复制的ID
4. 就可以看到该用户的所有收藏

## 💡 快速判断问题

### ✅ 正常情况

- 收藏后，`web_favorites` 表中**立即出现新记录**
- 退出登录后，记录**依然存在**
- 重新登录，记录**依然存在**
- 网站能正确显示收藏状态

### ❌ 有问题的情况

| 现象 | 可能原因 |
|------|---------|
| 收藏后数据库无新记录 | API未被调用或写入失败 |
| 退出后记录消失 | 代码错误删除了数据 |
| 记录存在但登录后不显示 | user_id 不匹配 |
| 收藏显示但数据库无记录 | 只存在localStorage，未同步到云端 |

## 🚨 常见问题

### Q1: 无法访问控制台？
**A:** 需要使用主账号登录，或者确保子账号有 CloudBase 查看权限

### Q2: 看不到 web_favorites 集合？
**A:** 确认环境ID是否正确：`cloudbase-1gnip2iaa08260e5`

### Q3: 数据不刷新？
**A:** 点击控制台右上角的刷新按钮，或者按 F5 刷新页面

### Q4: 时间不对？
**A:** 数据库存储的是 UTC 时间，北京时间需要 +8 小时
