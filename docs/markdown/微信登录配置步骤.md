## 🔴 第一步：填写授权回调域（5分钟）

### 1. 登录微信开放平台
- 网址：https://open.weixin.qq.com/
- 使用您的微信开放平台账号登录

### 2. 进入应用设置
- 点击顶部导航：**管理中心**
- 左侧菜单：**网站应用**
- 找到您的应用（应该已经创建好了）
- 点击应用名称进入详情页

### 3. 填写授权回调域
找到"授权回调域"配置项，填写：

```
mornhub.help
```

⚠️ **重要注意事项：**
- ❌ 不要写 `https://mornhub.help`（不要带协议）
- ❌ 不要写 `/api/auth/wechat/callback`（不要带路径）
- ✅ 只填域名本身：`mornhub.help`

### 4. 提交审核
- 点击"提交"或"保存"
- 个人开发者通常会立即通过
- 企业开发者可能需要1-2天

---

## 🟡 第二步：配置到项目（本地测试）

### 1. 打开本地环境变量文件
编辑文件：`.env.local`

### 2. 添加以下配置
```bash
# 微信登录配置
WECHAT_APP_ID=wxcf9a932db9c53cfe
WECHAT_APP_SECRET=62499fac74e065b37c45e651bc22eefa

# 网站地址（本地测试用localhost，部署后改为实际域名）
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# JWT密钥（用于生成登录Token，请保密）
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production

# 腾讯云数据库环境ID（您自己操作数据库，这个ID从腾讯云后台获取）
NEXT_PUBLIC_WECHAT_CLOUDBASE_ID=你的腾讯云环境ID
CLOUDBASE_SECRET_ID=你的腾讯云SecretId
CLOUDBASE_SECRET_KEY=你的腾讯云SecretKey
```

### 3. 获取腾讯云环境ID的步骤

**登录腾讯云控制台：**
1. 访问：https://console.cloud.tencent.com/tcb
2. 查看"环境列表"
3. 找到您创建的云开发环境
4. 复制"环境ID"（格式类似：`cloudbase-1gnip2iaa08260e5`）

**获取 SecretId 和 SecretKey：**
1. 访问：https://console.cloud.tencent.com/cam/capi
2. 点击"新建密钥"（或使用已有密钥）
3. 复制 `SecretId` 和 `SecretKey`
4. ⚠️ 保密这两个值！

## 🟢 第三步：配置到生产环境（部署时）

### Vercel 配置（如果部署到Vercel）
1. 进入 Vercel Dashboard
2. 选择项目 → Settings → Environment Variables
3. 添加以下变量：
   - `WECHAT_APP_ID` = `wxcf9a932db9c53cfe`
   - `WECHAT_APP_SECRET` = `62499fac74e065b37c45e651bc22eefa` （设置为Sensitive）
   - `NEXT_PUBLIC_SITE_URL` = `https://mornhub.help`
   - `JWT_SECRET` = `生产环境的JWT密钥` （设置为Sensitive）
   - `NEXT_PUBLIC_WECHAT_CLOUDBASE_ID` = `您的云开发环境ID`
   - `CLOUDBASE_SECRET_ID` = `您的腾讯云SecretId` （设置为Sensitive）
   - `CLOUDBASE_SECRET_KEY` = `您的腾讯云SecretKey` （设置为Sensitive）

### 腾讯云 Serverless 配置（如果部署到腾讯云）
1. 进入腾讯云 Serverless 控制台
2. 选择应用 → 环境变量管理
3. 添加上述相同的环境变量

## ⚠️ 常见问题

### Q1: "redirect_uri参数错误"
**原因：** 授权回调域未配置或配置错误
**解决：** 检查微信开放平台的授权回调域是否为 `mornhub.help`

### Q2: "appid参数错误"
**原因：** `WECHAT_APP_ID` 配置错误
**解决：** 检查 `.env.local` 中的 `WECHAT_APP_ID` 是否正确

### Q3: 本地测试微信登录无法回调
**原因：** 微信要求回调域名必须是公网可访问的域名
**解决：** 本地测试需要使用内网穿透工具（如ngrok）或直接部署到测试服务器

### Q4: 腾讯云数据库连接失败
**原因：** CloudBase环境ID或密钥配置错误
**解决：** 检查腾讯云控制台，确认环境ID、SecretId、SecretKey是否正确
