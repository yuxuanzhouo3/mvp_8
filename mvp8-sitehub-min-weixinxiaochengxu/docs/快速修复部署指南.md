## 🔍 常见问题诊断

### 问题1: "商户号配置错误"
```bash
原因: 商户号1694786758未认证或状态异常
解决:
  1. 登录微信商户平台
  2. 检查商户状态
  3. 完成实名认证
  4. 等待审核通过
```

### 问题2: "API密钥配置错误"
```bash
原因: API密钥长度不是32位或配置错误
解决:
  1. 登录微信商户平台
  2. 进入 API安全 → API密钥
  3. 重新设置32位密钥
  4. 更新云函数中的密钥 (line 371)
  5. 重新部署云函数
```

### 问题3: "签名验证失败"
```bash
原因: API密钥不匹配或签名算法错误
解决:
  1. 确认API密钥与商户平台一致
  2. 检查密钥是否包含特殊字符
  3. 验证签名算法 (generateSign函数)
  4. 查看云函数日志的签名字符串
```

### 问题4: "IP白名单限制"
```bash
原因: 云函数出口IP未添加到商户平台白名单
解决:
  1. 获取真实的云函数出口IP:
     // 在云函数中添加日志
     console.log('请求IP:', context.requestIP)

  2. 添加IP到商户平台白名单
  3. 等待5-10分钟生效
  4. 重新测试支付
```

### 问题5: "用户openid无效"
```bash
原因: 用户未登录或登录状态失效
解决:
  1. 清除小程序缓存
  2. 重新登录
  3. 检查wx.getStorageSync('sitehub_userInfo')
  4. 验证openid字段存在
```
