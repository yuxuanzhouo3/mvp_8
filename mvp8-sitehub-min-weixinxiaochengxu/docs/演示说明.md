# SiteHub 微信小程序 - 面试演示版

## 📱 项目简介
这是一个完整的微信小程序，实现了网站导航平台的核心功能，包含中英文国际化和微信登录功能。

## 🚀 快速预览步骤

### 1. 准备工具
- 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 使用微信扫码登录开发者工具

### 2. 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择此文件夹 `mvp8-native-miniprogram`
4. AppID选择"测试号"即可
5. 点击"导入"

### 3. 预览项目
- 点击工具栏的"预览"按钮
- 用手机微信扫描二维码即可在真机预览
- 或直接在开发者工具中查看效果

## ✨ 核心功能展示

### 🌍 国际化功能
- **默认中文界面**：打开后显示中文网站名称
- **右上角语言切换**：点击 🌐 按钮可切换中英文
- **IP自动检测**：支持根据地理位置自动设置语言（可选）

### 🔑 微信登录功能
- **左上角登录入口**：点击 👤 图标进入登录页面
- **微信授权登录**：支持获取微信用户信息
- **登录状态管理**：登录后显示用户头像
- **个人数据同步**：收藏数据与用户账号绑定

### 🌐 网站导航功能
- **晨光产品集**：20个产品横向滚动展示
- **网站分类**：支持分类筛选浏览
- **搜索功能**：中英文双语搜索
- **收藏功能**：长按网站可收藏/取消收藏
- **响应式设计**：适配不同屏幕尺寸

## 🎯 技术特点

- **原生微信小程序**：使用WXML、WXSS、JavaScript开发
- **数据架构**：采用"单一事实来源"设计模式
- **国际化系统**：完整的中英文本土化支持
- **用户体系**：微信登录 + 本地存储
- **UI设计**：现代化渐变背景 + 卡片式布局

## 📊 数据统计
- **网站数量**：185+ 个精选网站
- **产品数量**：20 个晨光系列产品
- **分类数量**：10+ 个网站分类
- **支持语言**：中文、English

## 🔧 如果遇到问题

1. **导入失败**：确保选择正确的项目文件夹
2. **功能异常**：检查微信开发者工具版本是否最新
3. **登录问题**：需要在真机或开发者工具中测试微信登录功能
