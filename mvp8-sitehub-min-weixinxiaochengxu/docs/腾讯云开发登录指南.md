## 🛠️ 常见操作指南

### 操作1：查看数据库数据

```bash
1. 登录云开发控制台
2. 点击"数据库"标签
3. 选择集合（如 users）
4. 查看数据列表
5. 可以筛选、搜索、编辑数据
```

### 操作2：查看云函数日志

```bash
1. 登录云开发控制台
2. 点击"云函数"标签
3. 选择要查看的函数（如 getUserProfile）
4. 点击"日志"
5. 查看调用记录和错误信息
```

### 操作3：测试云函数

```bash
1. 云函数 → 选择函数 → 点击"测试"
2. 输入测试参数（JSON格式）：
   {
     "userId": "test_user_001"
   }
3. 点击"运行测试"
4. 查看返回结果
```

### 操作4：导出数据库数据

```bash
1. 数据库 → 选择集合
2. 点击"导出"按钮
3. 选择导出格式（JSON/CSV）
4. 下载文件
```

## 🔒 安全建议

### 1. 数据库权限设置

```javascript
// 建议在控制台设置权限规则
{
  "read": "auth != null",  // 只有登录用户可读
  "write": "auth != null && doc._openid == auth.openid"  // 只能写自己的数据
}
```

### 2. 云函数安全

- 定期查看云函数调用日志
- 监控异常调用
- 设置调用频率限制

### 3. 账号安全

- 不要分享管理员账号
- 定期检查项目成员权限
- 使用微信扫码登录（更安全）

## 📞 遇到登录问题？

### 问题1：无法登录微信公众平台

**可能原因：**
- 不是小程序管理员
- 未被添加为项目成员
- 使用了错误的微信账号

**解决方案：**
1. 确认是否是管理员微信
2. 让管理员添加你为成员
3. 使用正确的微信扫码

### 问题2：看不到云开发入口

**可能原因：**
- 云开发未开通
- 权限不足

**解决方案：**
1. 联系管理员开通云开发
2. 确认自己的角色权限

### 问题3：数据库为空

**可能原因：**
- 选择了错误的环境
- 数据确实为空

**解决方案：**
1. 检查环境ID是否正确
2. 确认数据是否已初始化
