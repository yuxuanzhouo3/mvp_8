## 一、主流会员系统设计模式

### 1. Netflix模式
- ✅ **会员**: 大大的"Premium"徽章 + 下次扣费日期
- ❌ **免费**: 显示"免费试用"或"选择套餐"引导升级

- ✅ **会员**: "Premium" + 金色背景 + 无广告标识
- ❌ **免费**: "Free" + 灰色背景 + "升级到Premium"按钮

- ✅ **会员**: 金色VIP图标 + 有效期 + 特权列表
- ❌ **非会员**: 灰色普通用户 + "开通VIP"按钮

### 4. 微信读书无限卡模式
- ✅ **会员**: "无限卡会员" + 到期时间倒计时 + 权益展示
- ❌ **免费**: "普通用户" + "立即开通"

**共同特征**:
1. **视觉区分明显**: 会员用金色/紫色渐变，免费用灰色/白色
2. **状态清晰**: 会员显示到期时间，免费显示升级入口
3. **权益对比**: 清楚列出会员能做什么，免费有什么限制

## 四、🚨 潜在问题点

### 问题1: userSession.fetchMe() 可能返回旧数据
**可能原因**:
- callAIGateway云函数可能有缓存
- sitehub_users表更新了，但云函数读取的是旧快照

**验证方法**:
```javascript
// 在settings页面onShow中打印
console.log('📊 [诊断] fetchMe返回:', me)
console.log('📊 [诊断] entitlement.status:', me.entitlement.status)
console.log('📊 [诊断] isPro标志:', this.data.isPro)
console.log('📊 [诊断] subscription对象:', this.data.subscription)
```

### 问题2: subscription对象结构不匹配
**当前代码期望**:
```javascript
subscription: {
  status: 'active',
  plan_type: 'personal',
  current_period_end: Date,
  formattedExpiry: String,
  daysLeft: Number
}
```

**可能实际返回**:
```javascript
me.entitlement: {
  status: 'active',
  plan: 'pro',  // ⚠️ 不是 plan_type
  expiresAt: Date,  // ⚠️ 不是 current_period_end
}
```

### 问题3: loadSubscription() 没有被触发
**当前流程**:
1. onShow() 调用 fetchMe() 更新 isPro
2. 但没有调用 loadSubscription() 更新 subscription对象
3. 导致 `subscription === null` 或 `subscription.status !== 'active'`

## 五、✅ 完整修复方案

### 方案A: 统一使用 fetchMe() 数据（推荐）

修改 settings.js onShow():
```javascript
async onShow() {
  try {
    const { getUserSession } = require('../../utils/userSession')
    const userSession = getUserSession()
    
    // 强制刷新用户画像
    const me = await userSession.fetchMe(true)
    
    if (me && me.entitlement) {
      const isActive = me.entitlement.status === 'active'
      
      // 统一更新用户信息和会员状态
      this.setData({
        userInfo: {
          userId: me.userId,
          nickName: me.profile.nickname,
          avatarUrl: me.profile.avatar,
          isPro: isActive,
          memberStatus: me.entitlement.status,
          formattedCreatedAt: this.formatDate(me.profile.createdAt)
        },
        isPro: isActive,
        subscription: isActive ? {
          status: 'active',
          plan_type: me.entitlement.plan === 'pro' ? 'personal' : 'team',
          current_period_end: me.entitlement.expiresAt,
          formattedExpiry: this.formatExpiryDate(me.entitlement.expiresAt),
          daysLeft: this.calculateDaysLeft(me.entitlement.expiresAt),
          amount: me.entitlement.plan === 'pro' ? 19.99 : 299.99,
          billing_cycle: 'monthly'
        } : null
      })
    }
  } catch (error) {
    console.error('❌ [Settings] 加载失败:', error)
  }
}

// 新增工具方法
formatExpiryDate(dateString) {
  const date = new Date(dateString)
  return date.toLocaleDateString('zh-CN', {
    year: 'numeric',
    month: 'long',
    day: 'numeric'
  })
}

calculateDaysLeft(dateString) {
  const endDate = new Date(dateString)
  const now = new Date()
  const daysLeft = Math.ceil((endDate - now) / (1000 * 60 * 60 * 24))
  return daysLeft > 0 ? daysLeft : 0
}
```

### 方案B: 直接查询数据库（备选）

如果 fetchMe() 有缓存问题，直接查询数据库：
```javascript
async loadSubscriptionDirect() {
  const userInfo = wx.getStorageSync('sitehub_userInfo')
  
  // 直接查询订阅表
  const subsResult = await wx.cloud.database()
    .collection('sitehub_subscriptions')
    .where({
      user_openid: userInfo.openid,
      status: 'active'
    })
    .orderBy('created_at', 'desc')
    .limit(1)
    .get()
    
  if (subsResult.data.length > 0) {
    const sub = subsResult.data[0]
    this.setData({
      isPro: true,
      subscription: {
        status: 'active',
        plan_type: sub.plan_type,
        current_period_end: sub.current_period_end,
        formattedExpiry: this.formatExpiryDate(sub.current_period_end),
        daysLeft: this.calculateDaysLeft(sub.current_period_end),
        amount: sub.amount
      }
    })
  } else {
    this.setData({
      isPro: false,
      subscription: null
    })
  }
}
```
