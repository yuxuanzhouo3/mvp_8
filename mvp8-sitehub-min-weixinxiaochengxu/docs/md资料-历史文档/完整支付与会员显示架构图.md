# 🏗️ 完整支付与会员显示架构图

> **设计原则**：
> - ✅ 前端只做呈现，不做推理

## 🔄 完整支付流程（从点击支付到显示会员卡）

### 阶段1: 用户点击支付

```
用户点击"立即订阅"
    ↓
前端: payment.js 调用云函数
    ↓
云函数: wechatPaySubscription.createSubscription()
    ├─ 创建订阅记录 (status: 'pending')  ← 预备状态
    ├─ 生成微信支付参数
    └─ 返回支付参数给前端
    ↓
前端: wx.requestPayment(支付参数)
    ↓
跳转到微信支付界面
```

**此时数据库状态**:
```javascript
sitehub_subscriptions: {
  status: 'pending',  // ← 等待支付
  user_openid: 'xxx'
}

sitehub_users: {
  is_pro: false,  // ← 还不是会员
  subscription_status: 'free'
}
```

---

### 阶段2: 支付成功（关键环节）

```
用户完成支付
    ↓
微信支付系统返回成功
    ↓
前端: wx.requestPayment({ success: (payRes) => {...} })
    ↓
前端: payment.js.handlePaymentSuccess()
    │
    ├─ 【步骤1】更新订单表 (orders)
    │   └─ status: 'paid'
    │
    ├─ 【步骤2】更新订阅表 (sitehub_subscriptions) ⭐ 关键
    │   └─ status: 'pending' → 'active'
    │
    ├─ 【步骤3】更新用户表 (sitehub_users) ⭐ 唯一真相源
    │   ├─ is_pro: false → true
    │   ├─ subscription_status: 'free' → 'active'
    │   └─ subscription_expires_at: 设置到期时间
    │
    ├─ 【步骤4】更新本地缓存
    │   └─ wx.setStorageSync('sitehub_userInfo', {..., isPro: true})
    │
    └─ 【步骤5】刷新用户会话
        └─ userSession.fetchMe(true)  // 强制从后端重新获取
    ↓
前端: wx.navigateTo('/pages/settings/settings')
```

**此时数据库状态**:
```javascript
sitehub_subscriptions: {
  status: 'active',  // ✅ 已激活
  user_openid: 'xxx',
  current_period_end: '2025-11-12'
}

sitehub_users: {
  is_pro: true,  // ✅ 是会员
  subscription_status: 'active',
  subscription_expires_at: '2025-11-12'
}
```

**中间层翻译规则**:
```javascript
// callAIGateway/index.js
function translateUserData(dbUser, dbSubscription) {
  return {
    userId: dbUser.user_id,
    openid: dbUser.openid,
    profile: {
      nickname: dbUser.nickname,
      avatar: dbUser.avatar_url,
      createdAt: dbUser.created_at
    },
    entitlement: {
      // ⭐ 后端根据数据库计算出来的权益
      status: dbUser.is_pro && dbUser.subscription_status === 'active'
              ? 'active'
              : 'free',
      plan: dbSubscription?.plan_type || 'free',
      expiresAt: dbUser.subscription_expires_at,
      features: dbUser.is_pro
                ? ['unlimited', 'sync', 'no-ads']
                : ['limited-20', 'basic']
    }
  }
}
```

## 🎯 关键环节：后端是唯一真相源

### 前端的职责（只做呈现）

```javascript
// ❌ 错误做法：前端自己推理
if (订单已支付 && 金额大于0) {
  isPro = true  // 前端猜测是会员
}

// ✅ 正确做法：相信后端
const me = await api.getMe()
if (me.entitlement.status === 'active') {
  isPro = true  // 后端告诉我是会员
}
```

### 后端的职责（计算和验证）

```javascript
// 后端云函数: callAIGateway/index.js

async function getMe(openid) {
  // 1. 查询数据库（唯一真相源）
  const user = await db.collection('sitehub_users')
    .where({ openid })
    .get()

  const subscription = await db.collection('sitehub_subscriptions')
    .where({
      user_openid: openid,
      status: 'active'
    })
    .get()

  // 2. 后端计算权益状态（不要让前端猜）
  const now = new Date()
  const expiresAt = new Date(user.subscription_expires_at)
  const isExpired = expiresAt < now

  const entitlementStatus =
    user.is_pro === true &&
    user.subscription_status === 'active' &&
    !isExpired
      ? 'active'
      : 'free'

  // 3. 返回计算好的结果
  return {
    success: true,
    data: {
      userId: user.user_id,
      entitlement: {
        status: entitlementStatus,  // ← 后端算好的结果
        plan: subscription?.plan_type || 'free',
        expiresAt: user.subscription_expires_at,
        daysLeft: Math.ceil((expiresAt - now) / (1000*60*60*24))
      }
    }
  }
}
```

## 🐛 常见问题与解决方案

### 问题1: 数据库正确，但前端显示错误

**原因**: 后端API有缓存，或者查询逻辑错误

**解决**:
1. 检查 callAIGateway 的查询逻辑
2. 清除后端缓存
3. 添加日志查看返回值

### 问题2: 后端返回正确，但前端显示错误

**原因**: 前端有缓存，或者 onShow() 没有正确执行

**解决**:
1. 清除 userSession 缓存
2. 强制刷新页面
3. 重启小程序

### 问题3: 支付成功但数据库没更新

**原因**: handlePaymentSuccess 函数执行失败

**解决**:
1. 检查 payment.js 的 handlePaymentSuccess 函数
2. 添加错误日志
3. 手动修复数据库（执行修复脚本）

## 📐 架构原则总结

### ✅ 正确的分层

```
┌─────────────────────────────────────┐
│   前端 (Presentation Layer)         │
│   - 只负责渲染UI                     │
│   - 不做业务逻辑判断                 │
│   - 相信后端返回的数据               │
└─────────────────────────────────────┘
              ↓ ↑
┌─────────────────────────────────────┐
│   中间层 (API Gateway)              │
│   - 翻译前后端数据格式               │
│   - 统一错误处理                     │
│   - 权限验证                         │
└─────────────────────────────────────┘
              ↓ ↑
┌─────────────────────────────────────┐
│   后端 (Data & Logic Layer)         │
│   - 数据库是唯一真相源               │
│   - 计算所有业务逻辑                 │
│   - 验证所有输入                     │
└─────────────────────────────────────┘
```

### ❌ 错误的做法

```javascript
// ❌ 前端自己推理会员状态
if (本地缓存.支付时间 + 30天 > 现在) {
  显示会员卡
}

// ❌ 前端自己计算剩余天数

// ❌ 前端假设支付成功就是会员
if (支付成功) {
  isPro = true
}
```

### ✅ 正确的做法

```javascript
// ✅ 向后端请求真相
const me = await api.getMe()

// ✅ 后端告诉我是不是会员
if (me.entitlement.status === 'active') {
  显示会员卡
}

// ✅ 后端告诉我剩余天数
显示文本(me.entitlement.daysLeft + '天')

// ✅ 后端告诉我到期时间
显示文本(me.entitlement.expiresAt)
```
