#### ✅ Pro会员卡（会员用户）
- **视觉**: 紫色渐变卡片 (linear-gradient(135deg, #667eea 0%, #764ba2 100%))

#### ❌ 免费用户卡（非会员用户）
- **视觉**: 灰色卡片 (#f5f5f5背景)
- **标签**: "免费版" 灰色徽章
- **限制**:
  - • 收藏上限: 20个
  - • 自定义站点: 5个
- **引导**: "升级Pro解锁全部功能"
- **操作**: "立即升级" 按钮（紫色渐变）

### 显示逻辑（三重判断）

```javascript
// settings.wxml 第75行
wx:if="{{isPro && subscription && subscription.status === 'active'}}"
```

**三个条件必须同时满足**:
1. `isPro === true`
2. `subscription !== null`
3. `subscription.status === 'active'`

**只要有一个条件为false，就显示免费用户卡**
