## 📞 遇到问题？

### 常见问题速查

**Q: 剪贴板检测不工作？**
```
检查：
□ 是否在"自定义网站"分类页面
□ 是否复制了包含http/https的链接
□ 是否等待了2秒以上
□ 控制台有无错误日志
```

**Q: 识别不准确？**
```
可以在 utils/text-parser.js 中添加更多平台
```

**Q: 提示过于频繁？**
```
调整 index.js 中的检查间隔：
this.clipboardTimer = setInterval(() => {
  this.checkClipboard()
}, 5000) // 改为5秒
```
