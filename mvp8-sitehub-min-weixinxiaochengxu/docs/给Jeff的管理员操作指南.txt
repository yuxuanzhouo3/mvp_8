================================================================================
给 Jeff 的管理员操作指南
小程序上线 - 域名配置和审核提交
================================================================================

你好 Jeff，

小程序上线需要你配合完成以下操作。按照步骤执行即可。

================================================================================
第一部分：你需要收集的信息
================================================================================

请先联系开发者，获取以下信息：

✅ 1. 静态托管默认域名
   开发者会从云开发控制台获取一个类似这样的域名：
   cloudbase-1gnip2iaa08260e5-xxxxxxx.tcloudbaseapp.com
   
   收到后保存好，用于DNS配置。

✅ 2. 确认SSL证书文件位置
   你需要提供 SSL 证书文件给开发者上传
   文件名应该类似：site.mornscience.top_nginx.zip
   
   包含：
   - .pem 文件（证书文件）
   - .key 文件（私钥文件）

================================================================================
第二部分：DNS解析配置（你需要操作）
================================================================================

步骤1：登录腾讯云DNS控制台
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
访问：https://console.cloud.tencent.com/cns

步骤2：找到域名 mornscience.top
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在域名列表中找到 mornscience.top

步骤3：添加CNAME记录
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点击"解析" → 点击"添加记录"

填写内容：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
记录类型：CNAME
主机记录：site
记录值：[开发者给你的静态托管默认域名].tcloudbaseapp.com
TTL：600

示例：
记录类型：CNAME
主机记录：site
记录值：cloudbase-1gnip2iaa08260e5-1381819971.tcloudbaseapp.com
TTL：600

步骤4：保存
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点击"保存"

步骤5：等待生效（5-10分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
等待DNS生效后，验证：
nslookup site.mornscience.top

================================================================================
第三部分：给开发者提供SSL证书文件
================================================================================

步骤1：找到SSL证书文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
文件名：site.mornscience.top_nginx.zip

步骤2：发给开发者
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
解压后的文件包含：
- xxx.pem（证书文件）
- xxx.key（私钥文件）

把这两个文件发给开发者，他会上传到云开发。

================================================================================
第四部分：微信公众平台业务域名配置（你需要操作）
================================================================================

步骤1：登录微信公众平台
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
访问：https://mp.weixin.qq.com

步骤2：进入业务域名配置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：开发管理 → 开发设置 → 业务域名

步骤3：添加域名
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
输入域名：site.mornscience.top

步骤4：下载校验文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点击"下载校验文件"
文件名类似：wx1234567890.txt

步骤5：把校验文件发给开发者
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
把 wx开头的.txt 文件发给开发者
他会上传到静态托管根目录

步骤6：等待开发者上传完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
等开发者确认上传成功后，继续下一步

步骤7：验证访问
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在浏览器访问：
https://site.mornscience.top/wx1234567890.txt

如果能看到文件内容，说明配置成功

步骤8：完成验证
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
返回微信公众平台，点击"保存"按钮
微信会自动验证，成功后显示绿色对勾

步骤9：添加更多业务域名（可选）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
如果需要webview打开外部网站，可以添加：
https://www.google.com
https://github.com
https://twitter.com
https://facebook.com
...等等

注意：每个域名都需要下载校验文件，上传到对应网站根目录

================================================================================
第五部分：小程序基本信息配置（你需要操作）
================================================================================

步骤1：完善基本信息
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：设置 → 基本设置

配置：
- 小程序名称
- 小程序简介
- 小程序头像（正方形，比例1:1）
- 服务声明

步骤2：选择服务类目
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：设置 → 基本设置 → 服务类目

建议选择：
- 工具类 → 信息查询
- 工具类 → 效率工具
- 商业服务 → 信息服务

步骤3：配置隐私协议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：设置 → 隐私设置 → 用户隐私保护指引

添加权限说明：
- 获取位置信息
- 剪贴板（如果有自定义网站功能）
- 相册选择（如果有图片上传功能）

参考文案：
"我们将获取你的位置信息，用于为你推荐合适的网站。
我们可能会读取剪贴板内容，用于智能识别和解析你复制的网站链接。
你可以随时在设置中关闭此功能。"

================================================================================
第六部分：服务器域名配置（你需要操作）
================================================================================

步骤1：进入服务器域名配置
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：开发管理 → 开发设置 → 服务器域名

步骤2：添加域名
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
需要添加：
https://tcb-api.tencentcloudapi.com
https://wx-server.openapi.tencentcloudapi.com

注意：如果使用云开发，这些域名可能已经自动配置

================================================================================
第七部分：等待开发者上传代码
================================================================================

等开发者完成以下操作后，他会通知你：
1. 云函数已部署
2. 真机测试通过
3. 代码已上传到微信开发者工具

他会告诉你版本号，比如 v1.0.0

================================================================================
第八部分：提交审核（你需要操作）
================================================================================

步骤1：进入版本管理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
导航：版本管理 → 开发版本

步骤2：找到上传的版本
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
找到开发者上传的版本（版本号由开发者提供）

步骤3：提交审核
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点击"提交审核"

步骤4：填写审核信息
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
版本号：v1.0.0（或开发者提供的版本号）

更新说明：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SiteHub工具集 - 一站式网站导航平台
包含185个精选网站，17个分类
支持智能搜索、分类筛选、网站收藏

测试账号：（如果有登录功能，请填写）

功能页面：
提供小程序截图，展示核心功能

步骤5：提交
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
点击"提交"

步骤6：等待审核（1-3个工作日）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
审核结果会通知你

步骤7：审核通过后发布
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
审核通过后，点击"发布"按钮即可上线

如果被驳回：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
查看驳回原因，通知开发者修改后重新上传

================================================================================
第九部分：操作顺序总结
================================================================================

第一天：
1. 接收开发者给的"静态托管默认域名"
2. 配置DNS解析（site.mornscience.top）
3. 准备SSL证书文件，发给开发者

第二天：
4. 在微信公众平台下载业务域名校验文件
5. 把校验文件发给开发者上传
6. 验证域名可以访问
7. 完善小程序基本信息
8. 配置服务类目和隐私协议

第三天：
9. 等待开发者上传代码和测试结果
10. 提交审核

第四天：
11. 等待审核结果
12. 审核通过后发布
