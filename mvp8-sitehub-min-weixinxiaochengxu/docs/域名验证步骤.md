# 域名验证完整步骤

## 第一步: 获取微信提供的校验文件

1. **登录微信公众平台** (mp.weixin.qq.com)
2. **开发管理 → 开发设置 → 业务域名**
3. **点击"配置"或"添加"**
4. **下载校验文件** (文件名类似: wx1234567890.txt)

## 第二步: 上传校验文件到静态托管

### 方法A: 通过云开发控制台上传

1. **微信开发者工具 → 云开发**
2. **静态网站托管 → 文件管理**
3. **点击"上传文件"**
4. **选择刚下载的 wx开头的.txt 文件**
5. **确保上传到根目录** (不要放在文件夹里)

### 方法B: 通过文件管理器上传

1. 把校验文件复制到项目的 `cloudbase-static` 目录
2. 运行上传脚本: `./上传校验文件.sh`

## 第三步: 配置业务域名

### 选项A: 使用默认域名 (推荐,不需要DNS)

在微信公众平台业务域名中填写:
```
cloudbase-1gnip2iaa08260e5-1381819971.tcloudbaseapp.com
```

验证地址:
```
https://cloudbase-1gnip2iaa08260e5-1381819971.tcloudbaseapp.com/wx校验文件名.txt
```

### 选项B: 使用自定义域名 (需要先配置SSL证书和DNS)

1. 先完成下面的SSL证书配置
2. 配置DNS解析
3. 在微信公众平台填写: `site.mornscience.top`

## 第四步: 验证

1. 在浏览器访问验证地址
2. 确认能看到文件内容
3. 在微信公众平台点击"保存"
4. 微信会自动验证 ✅
