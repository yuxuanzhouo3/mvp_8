# 🔧 完整支付流程重构方案

> 问题：订阅记录 status=pending，但用户 is_pro=true，状态不一致

---

## 📊 当前状态分析

### 数据库状态
```
sitehub_subscriptions:
  - status: "pending" ❌ (应该是 "active")
  - amount: 19.99
  - plan_type: "personal"
  - billing_cycle: "monthly"
  - wechat_order_id: "sub_1760196240079_k5pzgng6e"

sitehub_users:
  - is_pro: true ✅
  - subscription_status: "active" ✅
  - subscription_expires_at: 2025-11-11 ✅
```

### 问题根因
支付成功后，订阅记录的 status 没有从 "pending" 更新为 "active"。

这是因为 `handlePaymentSuccess` 函数（payment.js 第143-225行）中：
- ✅ 更新了用户状态 (is_pro = true)
- ❌ 但没有更新订阅记录的 status

---

## ✅ 修复方案

### 关键修复点

**payment.js 的 handlePaymentSuccess 函数需要:**

1. ✅ 更新订单状态 (orders 表)
2. ⭐ **更新订阅状态** (sitehub_subscriptions 表) - 缺失
3. ✅ 更新用户状态 (sitehub_users 表)
4. ✅ 更新本地缓存

### 完整流程链路

```
用户点击支付
    ↓
前端: payment.js handlePayment()
    ↓
云函数: wechatPaySubscription createSubscription()
    ├─ 创建订阅记录 (status: "pending")
    ├─ 生成支付参数
    └─ 返回 orderNo + paymentParams
    ↓
前端: wx.requestPayment()
    ↓
微信支付 API
    ↓
支付成功回调: wx.requestPayment({ success })
    ↓
前端: handlePaymentSuccess(orderNo, userInfo, payRes)
    ├─ 1. 更新 orders 表: status = "paid"
    ├─ 2. ⭐ 更新 sitehub_subscriptions: status = "active" (新增)
    ├─ 3. 更新 sitehub_users: is_pro = true
    ├─ 4. 更新本地缓存: isPro = true
    └─ 5. 刷新用户会话
    ↓
跳转到设置页
    ↓
显示 Pro 会员状态 ✅
```

## 🔧 具体修复代码

### 修复 payment.js 的 handlePaymentSuccess

在 payment.js 第165-189行，添加订阅状态更新：

```javascript
async handlePaymentSuccess(orderId, userInfo, payRes = {}) {
  try {
    console.log('🔄 [Payment] 处理支付成功回调:', orderId)

    const transactionId = payRes.transaction_id || `real_txn_${Date.now()}`

    // 1️⃣ 更新订单状态为已支付
    console.log('💾 [Payment] 更新订单状态...')
    await wx.cloud.database()
      .collection('orders')
      .where({ orderNo: orderId })
      .update({
        data: {
          status: 'paid',
          transaction_id: transactionId,
          paidAt: new Date(),
          updatedAt: new Date()
        }
      })

    // 2️⃣ ⭐ 关键修复：更新订阅记录状态为 active
    console.log('📝 [Payment] 更新订阅状态为 active...')
    const subsUpdateResult = await wx.cloud.database()
      .collection('sitehub_subscriptions')
      .where({ wechat_order_id: orderId })
      .update({
        data: {
          status: 'active',  // ⭐ 从 pending 改为 active
          wechat_transaction_id: transactionId,
          updated_at: new Date()
        }
      })

    console.log('✅ [Payment] 订阅状态已更新:', subsUpdateResult.stats.updated, '条')

    // 3️⃣ 更新用户会员状态
    console.log('👤 [Payment] 更新用户会员状态...')

    // 先获取订阅的到期时间
    const subsResult = await wx.cloud.database()
      .collection('sitehub_subscriptions')
      .where({ wechat_order_id: orderId })
      .get()

    const subscription = subsResult.data[0]

    await wx.cloud.database()
      .collection('sitehub_users')
      .where({ openid: userInfo.openid })
      .update({
        data: {
          is_pro: true,
          subscription_status: 'active',
          subscription_expires_at: subscription?.current_period_end || new Date(),
          updated_at: new Date(),
          version: Date.now()
        }
      })

    // 4️⃣ 更新本地缓存
    this.updateLocalUserStatus(true)

    // 5️⃣ 更新全局状态
    const app = getApp()
    if (app.globalData.userInfo) {
      app.globalData.userInfo.pro = true
      app.globalData.userInfo.isPro = true
    }

    // 6️⃣ 强制刷新用户画像
    console.log('🔄 [Payment] 强制刷新用户画像...')
    try {
      const { getUserSession } = require('../../utils/userSession')
      const userSession = getUserSession()
      await userSession.fetchMe(true)
    } catch (e) {
      console.log('⚠️ [Payment] 用户会话刷新失败，跳过')
    }

    console.log('✅ [Payment] 支付成功处理完成！')

  } catch (error) {
    console.error('❌ [Payment] 处理支付回调失败:', error)
  }
}
```

### settings.js - 数据处理

在 onLoad 或 onShow 中添加：

```javascript
// 格式化订阅信息
async loadSubscriptionData() {
  try {
    const userInfo = wx.getStorageSync('sitehub_userInfo')

    // 获取订阅记录
    const subsResult = await wx.cloud.database()
      .collection('sitehub_subscriptions')
      .where({
        user_openid: userInfo.openid,
        status: 'active'
      })
      .orderBy('created_at', 'desc')
      .limit(1)
      .get()

    if (subsResult.data.length > 0) {
      const sub = subsResult.data[0]

      // 计算剩余天数
      const endDate = new Date(sub.current_period_end)
      const now = new Date()
      const daysLeft = Math.ceil((endDate - now) / (1000 * 60 * 60 * 24))

      this.setData({
        subscription: {
          ...sub,
          formattedExpiry: endDate.toLocaleDateString('zh-CN', {
            year: 'numeric',
            month: 'long',
            day: 'numeric'
          }),
          daysLeft: daysLeft > 0 ? daysLeft : 0,
          isExpiringSoon: daysLeft <= 7 && daysLeft > 0
        },
        isPro: true
      })
    } else {
      this.setData({
        subscription: null,
        isPro: false
      })
    }
  } catch (error) {
    console.error('加载订阅信息失败:', error)
  }
}
```
