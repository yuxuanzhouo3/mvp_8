## 📐 域名架构方案

### 当前阶段配置

```
小程序前端：site.mornscience.top  或  mini.site.mornscience.top
小程序API：api.site.mornscience.top
官网（未来）：www.site.mornscience.top
```

### 推荐方案：使用 `mini.site.mornscience.top`

**理由**：
- ✅ 便于区分小程序和官网流量
- ✅ 未来官网上线不冲突
- ✅ 便于统计和管理
- ✅ 其他端webview可以访问官网URL

**最终架构**（未来）：
```
mini.site.mornscience.top    # 小程序专用
site.mornscience.top         # 官网
api.site.mornscience.top     # API（小程序和官网共用）
其他端 → webview → site.mornscience.top
```

## ⚠️ 常见问题

### Q1: 应该使用 site.mornscience.top 还是 mini.site.mornscience.top？

**答**：推荐使用 `mini.site.mornscience.top`

**理由**：
- 未来官网用 `site.mornscience.top`
- 便于区分流量来源
- 其他端可以通过webview访问官网URL

---

### Q2: 业务域名验证失败怎么办？

**常见原因**：
- DNS未生效（等待10-30分钟）
- 校验文件位置错误（必须在根目录）
- 证书未配置（必须HTTPS）

**解决方案**：
1. 检查DNS解析是否生效：`nslookup mini.site.mornscience.top`
2. 检查HTTPS是否配置：访问 `https://mini.site.mornscience.top`
3. 检查校验文件：访问 `https://mini.site.mornscience.top/wx*.txt`

---

### Q3: webview打不开某些网站怎么办？

**原因**：业务域名未配置或未验证

**解决方案**：
- 方案1：让Jeff配置该域名为业务域名（需要验证）
- 方案2：使用中间跳转页面（不推荐）
- 方案3：只支持已验证的网站

---

### Q4: 云函数调用失败怎么办？

**检查清单**：
- [ ] 云函数是否已部署
- [ ] 云函数环境ID是否正确
- [ ] 服务器域名是否已配置
- [ ] 真机是否开启调试模式

**解决方案**：
1. 重新部署云函数
2. 检查云函数日志
3. 查看微信开发者工具Console错误信息

---

### Q5: 审核被驳回怎么办？

**常见驳回原因**：
- 功能描述不清楚
- 服务类目选择错误
- 隐私协议不完整
- 截图不清晰或缺失

**解决方案**：
1. 仔细阅读驳回原因
2. 按要求修改
3. 重新提交审核
