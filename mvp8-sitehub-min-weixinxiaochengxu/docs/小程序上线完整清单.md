🔨 **开发者操作**

#### 步骤1: 开通静态网站托管
```
1. 微信开发者工具 → 云开发按钮

3. 点击"开通"（如果未开通）
```

#### 步骤2: 获取静态托管默认域名
```
云开发控制台 → 静态网站托管 → 设置 → 默认域名
记录该域名，格式类似: cloudbase-1gnip2iaa08260e5-1381819971.tcloudbaseapp.com
```

**当前项目的云环境ID**: `cloudbase-1gnip2iaa08260e5`

**完成标准**: 记录下静态托管默认域名，发给 Jeff 用于DNS配置

### 1.3 SSL证书配置

🤝 **协作操作**

**需要的证书文件**: 
- 证书文件 (.pem)
- 私钥文件 (.key)

**Jeff需要提供**: 
- SSL证书文件（site.mornscience.top_nginx.zip）

**你的操作**（上传到云开发）:
```
云开发控制台 → 静态网站托管 → 设置 → 自定义域名 → 添加域名
1. 输入域名: site.mornscience.top
2. 选择证书类型: Nginx (pem + key)
3. 上传 Jeff 提供的证书文件和私钥文件
```

### 1.4 DNS解析配置

👨‍💼 **管理员操作** - Jeff完成

在腾讯云DNS控制台添加CNAME记录:

```
记录类型: CNAME
主机记录: site
记录值: [你提供的静态托管默认域名].tcloudbaseapp.com
TTL: 600
```

**示例**:
```
主机记录: site
记录值: cloudbase-1gnip2iaa08260e5-1381819971.tcloudbaseapp.com
```

**生效时间**: 5-10分钟

**验证方法**:
```bash
nslookup site.mornscience.top
```

## ⚠️ 七、常见问题

### Q1: 业务域名验证失败

**原因**:
- DNS未生效
- 校验文件位置错误
- 证书未配置

**解决方案**:
参考 `业务域名配置指南.md`

### Q2: webview 打不开

**原因**:
- 业务域名未配置
- 目标网站域名未添加到白名单

**解决方案**:
1. 配置业务域名
2. 或使用云开发的静态托管作为中转

### Q3: 云函数调用失败

**原因**:
- 云函数未部署
- 服务器域名未配置
- 权限问题

**解决方案**:
1. 部署云函数
2. 检查服务器域名配置
3. 检查云函数代码

### Q4: 审核被驳回

**常见原因**:
- 功能描述不清
- 缺少必要截图
- 服务类目选择错误
- 隐私协议不完整

**解决方案**:
根据驳回原因修改后重新提交
