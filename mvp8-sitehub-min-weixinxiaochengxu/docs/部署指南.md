## 🔧 部署步骤

### 步骤1: 配置Supabase数据库

1. **登录Supabase**
   ```
   访问: https://supabase.com/dashboard
   选择Jeff的团队项目
   ```

2. **执行SQL创建表**
   ```
   1. 进入项目 → SQL Editor
   2. 复制 supabase-setup.sql 内容
   3. 粘贴并执行
   4. 确认所有表创建成功
   ```

3. **验证表结构**
   ```sql
   SELECT table_name FROM information_schema.tables 
   WHERE table_schema = 'public' 
   AND table_name LIKE 'sitehub_%';
   ```

### 步骤2: 部署云函数

1. **在微信开发者工具中**
   ```
   1. 打开项目
   2. 右键 cloudfunctions/callAIGateway
   3. 选择"上传并部署: 云端安装依赖"
   4. 等待部署完成（约2-3分钟）
   ```

2. **验证云函数部署**
   ```
   1. 云开发 → 云函数 → callAIGateway
   2. 查看函数状态为"正常"
   3. 检查函数配置
   ```

### 步骤3: 配置微信云数据库

1. **创建数据集合**
   ```
   1. 云开发 → 数据库
   2. 创建集合: sitehub_data
   3. 设置权限: 所有用户可读写（开发阶段）
   ```

2. **验证环境配置**
   ```
   确认 app.js 中的环境ID正确:
   env: 'cloudbase-1gnip2iaa08260e5'
   ```

### 步骤4: 测试功能

1. **测试IP检测**
   ```
   1. 在开发者工具中预览
   2. 查看控制台日志
   3. 确认地域检测正常
   ```

2. **测试地域化显示**
   ```
   1. 中国IP → 显示中国网站
   2. 海外IP → 显示国际网站
   3. 手动切换功能
   ```

3. **测试数据保存**
   ```
   1. 收藏网站
   2. 检查对应数据库
   3. 验证数据同步
   ```

## 🐛 常见问题排查

### 1. IP检测不准确
```
问题: 检测结果与预期不符
解决: 
1. 检查云函数日志
2. 验证IP检测服务是否正常
3. 检查网络连接
4. 使用降级策略
```

### 2. 数据库连接失败
```
问题: Supabase连接失败
解决:
1. 检查URL和API Key
2. 验证网络连接
3. 检查防火墙设置
4. 查看Supabase项目状态
```

### 3. 云函数超时
```
问题: 函数执行超时
解决:
1. 检查AI API响应时间
2. 优化IP检测逻辑
3. 增加超时设置
4. 使用缓存机制
```

### 4. 数据不同步
```
问题: 数据未保存到正确数据库
解决:
1. 检查路由逻辑
2. 验证IP检测结果
3. 查看云函数日志
4. 测试数据库连接
```
