## ⚙️ 配置说明

此文件夹已在 `project.config.json` 中配置为上传时忽略：

```json
"packOptions": {
    "ignore": [
        {
            "type": "folder",
            "value": "docs"
        }
    ]
}
```

这样可以：
- ✅ 减少上传包大小
- ✅ 保持代码仓库整洁
- ✅ 避免文档文件占用小程序空间
