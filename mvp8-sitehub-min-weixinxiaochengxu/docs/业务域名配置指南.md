# 业务域名配置指南

## 问题描述

微信小程序需要配置业务域名 `site.mornscience.top`，需要上传校验文件进行验证。

由于我们使用的是**腾讯云开发(云开发)**模式部署小程序，没有传统的服务器，所以需要使用云开发的**静态网站托管**功能。

---

## 解决方案

### 方案1: 使用腾讯云开发静态网站托管 (推荐)

#### 第一步: 开通静态网站托管

1. **打开微信开发者工具**
2. **点击"云开发"按钮** (控制台右上角)
3. **进入云开发控制台**
4. **找到"静态网站托管"** (左侧菜单)
5. **点击"开通"** (如果还没开通的话)

#### 第二步: 上传校验文件

1. **下载微信提供的校验文件**
   - 文件名类似: `wxXXXXXXXXXXXXXXXX.txt`
   - 保存到本地

2. **上传到云开发静态托管**

   **方法A: 通过微信开发者工具上传**

   ```
   1. 云开发控制台 → 静态网站托管 → 文件管理
   2. 点击"上传文件"
   3. 选择下载的校验文件
   4. 上传到根目录 (不要放在子目录)
   ```

   **方法B: 通过命令行上传**

   ```bash
   # 安装腾讯云CLI工具
   npm install -g @cloudbase/cli

   # 登录
   tcb login

   # 上传文件到静态托管根目录
   tcb hosting deploy ./ -e cloudbase-1gnip2iaa08260e5
   ```

#### 第三步: 配置域名指向

1. **获取静态托管默认域名**
   - 云开发控制台 → 静态网站托管 → 设置
   - 复制默认域名 (类似: `xxx-xxx.tcloudbaseapp.com`)

2. **配置DNS解析**

   登录腾讯云DNS控制台，添加CNAME记录:

   ```
   记录类型: CNAME
   主机记录: site
   记录值: 你的静态托管默认域名 (例如: xxx-xxx.tcloudbaseapp.com)
   TTL: 600
   ```

3. **绑定自定义域名**

   - 云开发控制台 → 静态网站托管 → 设置 → 自定义域名
   - 点击"添加域名"
   - 输入: `site.mornscience.top`
   - 保存

#### 第四步: 验证配置

1. **等待DNS生效** (5-10分钟)

2. **访问验证文件**
   ```
   https://site.mornscience.top/wxXXXXXXXXXXXXXXXX.txt
   ```

   应该能看到文件内容

3. **在微信公众平台点击"保存"**
   - 返回业务域名配置页面
   - 点击"保存"按钮
   - 微信会自动验证文件

### 方案2: 使用云函数提供校验文件 (备选)

如果静态托管不可用，可以通过云函数返回校验文件内容。

#### 创建验证云函数

在 `cloudfunctions` 目录下创建 `domainVerify` 云函数:

```javascript
// cloudfunctions/domainVerify/index.js
const cloud = require('wx-server-sdk');
cloud.init();

exports.main = async (event, context) => {
  const { filename } = event;

  // 校验文件内容 (从微信公众平台下载后复制到这里)
  const verifyContent = '你的校验文件内容';

  return {
    content: verifyContent
  };
};
```

**问题**: 这个方案需要额外配置API网关，比较复杂，不推荐。

## 常见问题

### Q1: 静态托管域名在哪里?

A: 云开发控制台 → 静态网站托管 → 设置 → 默认域名

### Q2: DNS如何配置?

A:
```
类型: CNAME
主机记录: site
记录值: 你的静态托管域名.tcloudbaseapp.com
```

### Q3: 校验文件要上传到哪里?

A: 静态托管的**根目录**，不要放在子文件夹

### Q4: 验证失败怎么办?

A: 检查:
1. DNS是否生效 (用 `nslookup site.mornscience.top`)
2. 文件是否在根目录
3. 文件是否可以公开访问
4. 域名是否绑定成功

---

## 注意事项

⚠️ **重要提醒**:

1. 静态托管需要单独开通（免费额度足够使用）
2. DNS解析需要5-10分钟生效
3. 域名必须已备案（site.mornscience.top）
4. 校验文件名不能改，必须使用微信提供的文件名
5. 上传后访问 `https://site.mornscience.top/文件名.txt` 确认可访问
