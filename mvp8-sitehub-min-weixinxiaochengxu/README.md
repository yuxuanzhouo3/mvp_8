# 🚀 MVP8 SiteHub 微信小程序版

## 📋 项目简介
这是MVP8 SiteHub工具集的微信小程序版本，将原本的Next.js网页版本改造为微信小程序，实现了以下功能：

### ✨ 核心功能
- 🌟 **MornHub特色产品展示** - 展示3个核心产品
- 🔍 **网站搜索功能** - 支持网站名称和分类搜索  
- 🏷️ **分类筛选** - 按工具、社交、购物、视频、金融等分类筛选
- 📱 **响应式网格布局** - 完美适配各种屏幕尺寸
- 🌐 **网页浏览** - 点击网站可在小程序内浏览
- 🎨 **本土化UI设计** - 专为中国用户设计的深色主题

### 📱 包含网站
- **特色产品**: MornHub、MornHomes、MornTech
- **常用网站**: 百度、微信、淘宝、京东、哔哩哔哩、支付宝等
- **国际网站**: Google、GitHub、YouTube、Netflix、Amazon等
- **总计**: 20+个精选网站，支持无限扩展

## 🛠 使用方法

### 方法1: 微信开发者工具 (推荐)
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具
3. 选择"导入项目"
4. 选择此文件夹路径: \`mvp8-native-miniprogram\`
5. AppID可以使用测试号，或输入: \`wx0123456789abcdef\`
6. 点击"导入"
7. 点击"预览"或"真机调试"即可体验

### 方法2: 一键预览 
1. 确保项目完整性，所有文件都在
2. 微信开发者工具 → 文件 → 打开 → 选择项目文件夹
3. 编译成功后点击"预览"
4. 微信扫码即可在真机体验

## 🔧 自定义配置

### 添加新网站
编辑 \`pages/index/index.js\` 文件中的 \`allSites\` 数组:

```javascript
{
  id: "新网站id",
  name: "网站名称", 
  url: "https://网站地址.com",
  logo: "🔗", // emoji图标
  category: "tools" // 分类
}
```

### 修改特色产品
编辑 \`pages/index/index.js\` 文件中的 \`featuredSites\` 数组。

### 调整UI样式
修改对应的 \`.wxss\` 样式文件。
